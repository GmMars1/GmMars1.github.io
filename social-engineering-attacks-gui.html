01 / 07EMAIL ATTACK

PHISHING

Deceptive emails crafted to steal credentials or deploy malware.

HOW IT WORKS

  1. 1Attacker spoofs a trusted sender (bank, PayPal, IT dept).
  2. 2Urgent pretext: “Your account is suspended — verify now.”
  3. 3Link points to a pixel-perfect cloned login page (typosquatting).

REAL-WORLD EXAMPLE

● ● ● example.log
From: support@paypa1.com [note: ‘1’ not ‘l’]
Subject: Unusual Sign-In Detected – Verify Account
→ Fake PayPal page harvests credentials + card info

RED FLAGS

  • Mismatched domain (paypa1.com ≠ paypal.com)
  • Urgent language (“Act now or account gets locked”)
  • Hover URL ≠ displayed anchor text in email

DEFENSE TIP

Never click email links. Navigate directly in browser. Enable MFA on every account.

02 / 07VOICE ATTACK

VISHING

Voice phishing via phone calls impersonating trusted authorities.

HOW IT WORKS

  1. 1Caller ID spoofed to show IRS, bank, or tech support number.
  2. 2AI voice cloning enables real-time executive impersonation.
  3. 3Victim pressured to reveal OTPs, SSNs, or wire transfers.

REAL-WORLD EXAMPLE

● ● ● example.log
“This is IRS Agent #4821. You owe $3,200.”
“Pay via gift cards to avoid immediate arrest.”
→ Gift card numbers extracted live over the call

RED FLAGS

  • Unsolicited call demanding immediate payment
  • Refuses to give a verifiable callback number
  • Creates fear/urgency — arrest, lawsuit, account freeze

DEFENSE TIP

Hang up. Call the organization directly using the official number on their website.

03 / 07SMS ATTACK

SMISHING

SMS-based phishing using mobile messages to harvest sensitive data.

HOW IT WORKS

  1. 1Texts sent via spoofed numbers or bulk SMS gateways.
  2. 2Short URLs (bit.ly) hide the real malicious destination.
  3. 3Mobile browsers truncate URLs — much harder for victims to verify.

REAL-WORLD EXAMPLE

● ● ● example.log
“FedEx: Your package #749 is held at facility.”
“Confirm delivery address: http://bit.ly/fdx-conf”
→ Harvests full name, address, and card details

RED FLAGS

  • Unexpected delivery or bank SMS with shortened links
  • Requests sensitive info via a link (banks never do this)
  • Grammar errors or mismatched branding in the message

DEFENSE TIP

Never tap SMS links. Open the official app or website directly to check status.

04 / 07IDENTITY FRAUD

PRETEXTING

Fabricating a false identity or scenario to extract sensitive info.

HOW IT WORKS

  1. 1Attacker profiles target via OSINT (LinkedIn, company site).
  2. 2Constructs a believable role: fake vendor, HR, IT auditor.
  3. 3Builds rapport over multiple interactions before the final ask.

REAL-WORLD EXAMPLE

● ● ● example.log
“Hi, I’m Sarah from IT Compliance team.”
“We’re running a security audit this week – I need your AD password to validate accounts in scope.”

RED FLAGS

  • Requests that bypass normal verification procedures
  • Over-familiarity using OSINT data to appear legitimate
  • Cannot provide verifiable employee ID or department contact

DEFENSE TIP

Always verify identity through official internal channels before sharing any information.

05 / 07PHYSICAL + DIGITAL

BAITING

Luring victims using enticing physical media or fake digital downloads.

HOW IT WORKS

  1. 1USB drives labeled ‘SALARY_2025.xlsx’ dropped in parking lots.
  2. 2Malicious AutoRun / LNK files execute reverse shell on insertion.
  3. 3Online: pirated software bundled with RATs and keyloggers.

REAL-WORLD EXAMPLE

● ● ● example.log
USB labeled ‘Confidential – Layoffs Q4 2025’ at lobby
→ Curious employee inserts it at their workstation
→ AutoRun triggers – reverse shell connects to attacker C2

RED FLAGS

  • Found USB / CD with an intriguing or sensitive-looking label
  • Free software downloads from unofficial or cracked sources
  • Files using double extensions: report.pdf.exe

DEFENSE TIP

Never plug in unknown USB devices. Disable AutoRun via Group Policy. Use USB condoms.

06 / 07FALSE EXCHANGE

QUID PRO QUO

Offering a fake service or benefit in exchange for credentials or access.

HOW IT WORKS

  1. 1Attacker cold-calls posing as IT support offering a ‘free scan’.
  2. 2Victim hands over remote access credentials for the ‘fix’.
  3. 3Session used to install RATs, exfiltrate data, pivot the network.

REAL-WORLD EXAMPLE

● ● ● example.log
“Hi, Microsoft detected a virus on your PC.”
“Allow me to remote in and remove it for free now.”
→ TeamViewer session hijacked – full persistent access

RED FLAGS

  • Unsolicited offer of free IT help or system optimization
  • Requests installation of remote access tool (AnyDesk / TeamViewer)
  • Asks you to disable antivirus ‘temporarily’ for the fix

DEFENSE TIP

IT never calls employees unprompted. Report all unsolicited support calls to your security team.

07 / 07PHYSICAL BREACH

TAILGATING

Physically following authorized personnel into restricted secure areas.

HOW IT WORKS

  1. 1Attacker stands near badge-access door with hands full (boxes).
  2. 2Exploits social courtesy — employees hold doors out of politeness.
  3. 3Once inside: installs keyloggers, network taps, or plants bugs.

REAL-WORLD EXAMPLE

● ● ● example.log
Attacker in uniform carries boxes toward server room
→ Employee swipes badge and politely holds door open
→ Attacker plants LAN Turtle network tap – undetected

RED FLAGS

  • Unknown person follows closely without badging independently
  • Unfamiliar ‘vendor’ or ‘delivery person’ wants unescorted access
  • Unusual curiosity about server rooms or network closets

DEFENSE TIP

Challenge all unrecognized people. Each employee owns the badge — always badge separately.
