# GmMars1.github.io

Static GitHub Pages repository for OSINT bookmarklet resources.

## Overview

This repository hosts a bookmarklet collection page and related GitHub Pages configuration.
The primary content is a Netscape-format bookmark export:

- `/home/runner/work/GmMars1.github.io/GmMars1.github.io/My OSINT Bookmarklets.html`

## Repository Structure

- `/home/runner/work/GmMars1.github.io/GmMars1.github.io/My OSINT Bookmarklets.html`  
  Main bookmarklet collection content.
- `/home/runner/work/GmMars1.github.io/GmMars1.github.io/CNAME`  
  Custom domain configuration for GitHub Pages.
- `/home/runner/work/GmMars1.github.io/GmMars1.github.io/AGENTS.md`  
  Contributor/agent workflow guidance for this repository.

## Usage

### View as a webpage
Open the published GitHub Pages site for this repository domain.

### Import bookmarklets into a browser
1. Open your browser bookmarks manager.
2. Use the import option for bookmarks.
3. Select `My OSINT Bookmarklets.html`.

## Notes

- This repository does not currently use a package/build system (no `package.json`, `pyproject.toml`, `Gemfile`, or `Makefile`).
- Updates are typically direct file edits to static content.
